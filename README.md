# 🤝 Моё дело — Волонтёрская платформа помощи пожилым людям

**«Моё дело»** — социальная платформа, которая соединяет пожилых людей и людей с ОВЗ с волонтёрами и специалистами для бытовой помощи.

## 📱 Как это работает

1. **Заказчик** (пожилой человек) нажимает «Оформить заказ»
2. Пишет простыми словами: *«Прорвало кран, вода льётся»*
3. **ИИ-классификатор** определяет: категория (Сантехника 🔧), приоритет (Срочно 🔴)
4. Заказ рассылается **исполнителям в радиусе 1 км**
5. Исполнитель принимает → выполняет → заказчик оценивает ⭐ 1–5

## 🛠 Технологический стек

## 🚀 Быстрый старт

### 1. Настройка Termux (Android)

```bash
# Установка зависимостей
pkg update && pkg upgrade
pkg install golang git postgresql

# Запуск PostgreSQL
initdb $PREFIX/var/lib/postgresql
pg_ctl -D $PREFIX/var/lib/postgresql start

# Создание БД и пользователя
createuser --superuser moe_user
createdb -O moe_user moe_delo
```

### 2. Запуск бэкенда

```bash
cd backend

# Установка зависимостей Go
go mod tidy

# Заполнение тестовыми данными
go run cmd/seed/main.go

# Запуск сервера
go run cmd/server/main.go
```

Сервер запустится на `http://localhost:8080`

### 3. Тестирование API

```bash
# Регистрация заказчика
curl -X POST http://localhost:8080/auth/register \
  -H "Content-Type: application/json" \
  -d '{"phone":"+79001112233","password":"demo1","role":"customer","first_name":"Мария Ивановна"}'

# Вход
curl -X POST http://localhost:8080/auth/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"+79001112233","password":"demo1"}'

# Создание заказа (с токеном)
curl -X POST http://localhost:8080/api/orders \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"description":"Прорвало кран, вода льётся","address":"ул. Ленина, 15","lat":55.7558,"lon":37.6173}'

# Заказы рядом (1 км)
curl "http://localhost:8080/api/orders/nearby?lat=55.7558&lon=37.6173&radius=1000" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Принять заказ
curl -X POST http://localhost:8080/api/orders/1/accept \
  -H "Authorization: Bearer EXECUTOR_TOKEN"

# Завершить заказ
curl -X POST http://localhost:8080/api/orders/1/complete \
  -H "Authorization: Bearer EXECUTOR_TOKEN"

# Оценить
curl -X POST http://localhost:8080/api/orders/1/rate \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer CUSTOMER_TOKEN" \
  -d '{"score":5,"comment":"Спасибо, всё отлично!"}'

# Проверка здоровья
curl http://localhost:8080/health
```

### 4. Сборка Flutter APK

```bash
cd mobile

# Установка зависимостей
flutter pub get

# Запуск в режиме разработки
flutter run

# Сборка release APK
flutter build apk --release

# APK будет в: build/app/outputs/flutter-apk/app-release.apk
```

### 5. CLI-утилиты

```bash
# Админ-панель
go run cmd/admin/main.go list       # Список пользователей
go run cmd/admin/main.go orders     # Список заказов
go run cmd/admin/main.go role 2 executor  # Сменить роль
go run cmd/admin/main.go delete 3   # Удалить пользователя

# Проверка здоровья
go run cmd/health/main.go           # localhost:8080
go run cmd/health/main.go http://myserver.com  # Указать URL
```

## 🎤 Доступность и помощь

### Голосовой ввод заказа
- 🎤 Кнопка микрофона рядом с полем описания
- Поддержка русского языка (`ru_RU`)
- Автоматическая остановка через 10 секунд
- Мгновенная ИИ-классификация произнесённого текста

### Озвучка интерфейса (TTS)
- 🔊 Кнопка «Прослушать» на всех главных экранах
- Русский голос, скорость 0.5 (комфортная для пожилых)
- Озвучка подсказок, заказов, приветствий

### Экстренная кнопка SOS
- 🆘 Большая красная кнопка на главном экране заказчика
- Долгое нажатие → SMS + звонок доверенному контакту
- Автоматическая отправка геолокации в SMS
- Если контакт не указан — звонок в 112

### Доверенный контакт
- 👨‍👩‍👧 Поле «Телефон родственника» в профиле
- Сохраняется в SharedPreferences
- Используется для SOS-вызова

## 🤖 ИИ-классификатор

Определяет категорию и приоритет по ключевым словам:

**Приоритет 1 (срочно):** «срочно», «авария», «затопило», «прорвало», «пожар»

**Категории:**
- 🔧 Сантехника: кран, труб, вода, слив, унитаз
- ⚡ Электрика: розетк, провод, свет, лампочк
- 🧹 Уборка: убор, пылесос, мыть, чист
- 📦 Доставка: достав, привез, купить, продук
- 🔨 Ремонт: ремонт, мебел, дверь, повесить
- 🚶 Сопровождение: сопровожд, помочь, дойти, поликлиник
